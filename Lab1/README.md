# Lab 1: AI Environment, Production Systems, and Search Problems

This lab introduces rule-based reasoning and state-space problem solving.

## Included scripts
- `Experiment1.py` checks the active Python environment and package availability.
- `Experiment2.py` implements production rules, rule-based decision making, water jug, missionaries and cannibals, and vacuum cleaner search demos.

## Run the demonstrations

From the repository root:

```bash
python3 Lab1/Experiment1.py
python3 Lab1/Experiment2.py
```

The search work uses breadth-first search over tuple-based states, and each transition records the action and result state.
The `outputs/` folder is reserved for generated result files.
